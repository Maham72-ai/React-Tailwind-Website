PakBazaar.pk - Pakistani Fashion Store
PakBazaar.pk is an online shopping website for authentic Pakistani dresses, footwear and accessories. This website is built using React and Tailwind CSS.

It showcases traditional Pakistani culture like Lawn Suits, Kurta Shalwar, Peshawari Chappal, Khussa and Jewellery from local artisans of Lahore, Karachi, Multan and Peshawar.

Features
Home page with Pakistani fashion collection
Products page with category filter (Women, Men, Footwear, Jewellery, etc.)
Product Detail page - click on any product to view full details
Add to Cart functionality with cart counter
About page with our vision and mission
Login and Register pages
Fully responsive design for mobile and desktop
Clean and simple UI
Tech Stack
Frontend: React.js
Styling: Tailwind CSS
Routing: React Router DOM
Build Tool: Vite
Pages Included
Home - Introduction to Pakistani fashion store
Products - All products with filter option
Product Detail - Detailed view of each product
About - Information about PakBazaar.pk and our vision
Login - User login page
Register - New user registration page

## Our Vision

Our vision is to become Pakistan's most trusted online marketplace for traditional clothing. We want to empower local artisans from Faisalabad, Multan, Karachi and Peshawar by giving their handmade products a digital platform. We believe in preserving Pakistani heritage through fashion.

We focus on:
- 100% Original Pakistani Products
- Cash on Delivery all over Pakistan
- Affordable Pricing
- Supporting Local Artisans
